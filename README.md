# gaugemap

Gauge config/map key checks for twelve-factor services.

**Site:** https://theworker02.github.io/gaugemap/

## Install / run

```bash
git clone https://github.com/theworker02/gaugemap.git
cd gaugemap
node src/cli.js
node --test
```
